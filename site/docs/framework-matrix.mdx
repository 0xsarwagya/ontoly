| Framework or Surface | Status | Notes |
| -------------------- | ------ | ----- |
| JavaScript projects | Supported | JS, JSX, MJS, CJS, ESM, and CommonJS |
| TypeScript projects | Supported | TS, TSX, MTS, and CTS |
| NestJS-style APIs | Validated | Validated through examples and corpus fixtures |
| Turborepo workspaces | Validated | Workspace graph validation present |
| React | Corpus fixture | Validation evidence only |
| Next.js | Corpus fixture | Validation evidence only |
| Express | Supported routes | Deterministic call-style route facts for JavaScript and TypeScript |
| Fastify | Supported routes | Deterministic call-style route facts for JavaScript and TypeScript |
| Hono | Supported routes | Deterministic call-style route facts for JavaScript and TypeScript |
| OpenAPI | Experimental | Schema-driven graph facts |
| Prisma | Roadmap | Not implemented |
| GraphQL | Roadmap | Not implemented |

Framework coverage should be measured through [Validation Lab](./validation-lab), not inferred from package names alone.
