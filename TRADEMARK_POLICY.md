This policy explains how the Ontoly name, logos, marks, and project identity may
be used.

## Protected Marks

The protected marks include:

- Ontoly;
- Ontoly logos and visual identity;
- package, plugin, and Agent Skill names that include Ontoly;
- names or marks confusingly similar to Ontoly.

## Permitted Use

You may use the Ontoly name to:

- refer truthfully to the project;
- describe compatibility with Ontoly;
- link to the Ontoly repository or documentation;
- identify unmodified copies of Ontoly distributed under the project license;
- discuss Ontoly in articles, talks, tutorials, benchmarks, or documentation.

## Restricted Use

You may not use Ontoly marks in a way that:

- implies endorsement, sponsorship, partnership, or official status without
  written permission;
- names a product, company, service, package, hosted offering, or commercial
  integration in a way that suggests it is official Ontoly;
- misrepresents modified versions as the official project;
- damages the reputation or goodwill of the project or creator.

## Forks And Modified Versions

Forks and modified versions must make it clear that they are not the official
Ontoly project unless written permission is granted.

Use names such as "Foo for Ontoly" or "Foo compatible with Ontoly" only when the
relationship is accurate and not misleading.
