# Refactoring Examples

Each example is graph-first and MCP-first.

| Repository | Questions | Expected workflow | Capabilities invoked | Expected evidence | Expected answer |
| --- | --- | --- | --- | --- | --- |
| NestJS | Trace a request through a NestJS controller, guard, and service. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependencies` then `FindDependents` then `FindCycles`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependencies`, `FindDependents`, `FindCycles` | controller, route, service, dependency-injection edges; graph hash; confidence. | A refactoring plan with blast radius, dependency order, validation steps, and confidence. |
| Express | Explain the package entrypoint and public API surface. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependencies` then `FindDependents` then `FindCycles`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependencies`, `FindDependents`, `FindCycles` | package, exports, functions, interfaces; graph hash; confidence. | A refactoring plan with blast radius, dependency order, validation steps, and confidence. |
| Hono | Find middleware APIs and their consumers before a refactor. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependencies` then `FindDependents` then `FindCycles`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependencies`, `FindDependents`, `FindCycles` | functions, interfaces, dependents, configuration; graph hash; confidence. | A refactoring plan with blast radius, dependency order, validation steps, and confidence. |
| Turborepo | Summarize workspace packages and package dependencies. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependencies` then `FindDependents` then `FindCycles`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependencies`, `FindDependents`, `FindCycles` | workspace, packages, framework nodes, dependency edges; graph hash; confidence. | A refactoring plan with blast radius, dependency order, validation steps, and confidence. |
| Next.js | Identify app routes and request ownership. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependencies` then `FindDependents` then `FindCycles`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependencies`, `FindDependents`, `FindCycles` | routes, route handlers, modules, services; graph hash; confidence. | A refactoring plan with blast radius, dependency order, validation steps, and confidence. |
