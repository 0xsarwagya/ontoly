# Security Review Examples

Each example is graph-first and MCP-first.

| Repository | Questions | Expected workflow | Capabilities invoked | Expected evidence | Expected answer |
| --- | --- | --- | --- | --- | --- |
| NestJS | Trace a request through a NestJS controller, guard, and service. | Follow shared workflow, run `EvidencePack` first, then `FindAuthenticationFlow` then `FindResponsibleFunction` then `TraceRequestLifecycle` then `FindConfigurationUsage`, inspect files only if graph evidence is missing. | `EvidencePack`, `FindAuthenticationFlow`, `FindResponsibleFunction`, `TraceRequestLifecycle`, `FindConfigurationUsage` | controller, route, service, dependency-injection edges; graph hash; confidence. | A security flow summary with auth nodes, authorization edges, missing evidence, and confidence. |
