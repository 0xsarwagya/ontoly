# Dead Code Analysis Examples

Each example is graph-first and MCP-first.

| Repository | Questions | Expected workflow | Capabilities invoked | Expected evidence | Expected answer |
| --- | --- | --- | --- | --- | --- |
| NestJS | Trace a request through a NestJS controller, guard, and service. | Follow shared workflow, run `EvidencePack` first, then `FindDeadCode` then `FindUnusedFeature` then `FindEntrypoints` then `FindDependents`, inspect files only if graph evidence is missing. | `EvidencePack`, `FindDeadCode`, `FindUnusedFeature`, `FindEntrypoints`, `FindDependents` | controller, route, service, dependency-injection edges; graph hash; confidence. | A cautious dead-code report with candidates, false-positive checks, evidence, and confidence. |
