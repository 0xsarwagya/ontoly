# Impact Analysis Examples

Each example is graph-first and MCP-first.

| Repository | Questions | Expected workflow | Capabilities invoked | Expected evidence | Expected answer |
| --- | --- | --- | --- | --- | --- |
| NestJS | Trace a request through a NestJS controller, guard, and service. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependents` then `FindDependencies` then `FindNode`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependents`, `FindDependencies`, `FindNode` | controller, route, service, dependency-injection edges; graph hash; confidence. | A ranked blast-radius report with direct and transitive dependents, evidence edges, and confidence. |
| Express | Explain the package entrypoint and public API surface. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependents` then `FindDependencies` then `FindNode`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependents`, `FindDependencies`, `FindNode` | package, exports, functions, interfaces; graph hash; confidence. | A ranked blast-radius report with direct and transitive dependents, evidence edges, and confidence. |
| Hono | Find middleware APIs and their consumers before a refactor. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependents` then `FindDependencies` then `FindNode`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependents`, `FindDependencies`, `FindNode` | functions, interfaces, dependents, configuration; graph hash; confidence. | A ranked blast-radius report with direct and transitive dependents, evidence edges, and confidence. |
| Turborepo | Summarize workspace packages and package dependencies. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependents` then `FindDependencies` then `FindNode`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependents`, `FindDependencies`, `FindNode` | workspace, packages, framework nodes, dependency edges; graph hash; confidence. | A ranked blast-radius report with direct and transitive dependents, evidence edges, and confidence. |
| Next.js | Identify app routes and request ownership. | Follow shared workflow, run `EvidencePack` first, then `ImpactAnalysis` then `FindDependents` then `FindDependencies` then `FindNode`, inspect files only if graph evidence is missing. | `EvidencePack`, `ImpactAnalysis`, `FindDependents`, `FindDependencies`, `FindNode` | routes, route handlers, modules, services; graph hash; confidence. | A ranked blast-radius report with direct and transitive dependents, evidence edges, and confidence. |
